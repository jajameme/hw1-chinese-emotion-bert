# 作業一實作紀錄：BERT 多元情緒分類

## 依據與範圍

依原工作區的「作業一實作計畫：BERT 多元情緒分類」建立本專案。沿用課程 `cases/bert_finetune` 的資料準備、`Trainer` 微調、推論與畫圖流程，改為 8 類情緒分類。計畫文件是實作參考，資料集的實際 CSV 標籤與執行結果以現場檢查為準。

## 實作過程

1. 檢查本機環境：`nvidia-smi` 顯示 NVIDIA GeForce GTX 1660 Ti，6,144 MiB VRAM，驅動 572.42、CUDA Version 12.8。系統 `python` 指向 MSYS Python 3.12.7；專案的 `.venv` 改用 Anaconda Python 3.12.7 建立，避免 Python 來源混淆。
2. 建立 `check_gpu.py`，檢查 PyTorch、CUDA 裝置、compute capability、VRAM 與一輪 FP16 矩陣乘法的數值是否有限。
3. 建立 `download_data.py`。從 Hugging Face 下載原始 `data.csv` 至 `data/raw.csv`；也可指定已手動下載的 CSV。既有檔案預設不覆寫，寫入時先使用暫存檔並確認欄位。
4. 建立 `prepare_data.py`。讀取 `text`、`emotion`，去空白、空值、重複句；若同一句有衝突標籤，整句移除。從 CSV 的實際 unique 標籤排序建立 `label2id` 與 `id2label`，以 seed 42 分層切成 80% / 10% / 10%。JSONL 欄位為 `sentences` 與 `labels`，供 `Trainer` 讀取。
5. 建立 `train_bert.py`。使用 `bert-base-chinese`、長度 128、dynamic padding、batch 16、gradient accumulation 2、FP16 開關、學習率 2e-5。最多 5 epochs，每 50 optimizer steps 驗證與儲存，早停耐心 3 次；以驗證集 macro-F1 選 best model。訓練後只對 test set 評估一次，儲存 classification report、混淆矩陣和 best model，清理過程 checkpoint。
6. 建立 `infer_bert.py`，對計畫指定的五句輸出 `句子 => 標籤 (四位小數)`；建立 `plot_bert_metrics.py`，根據 `trainer_state.json` 產生 loss 和 macro-F1 圖。
7. 建立獨立 README、requirements、`.gitignore` 和 `.gitattributes`。排除虛擬環境、資料、過程 checkpoint 與 Python 快取；保留成果圖及最終模型，並為 `.safetensors` 設定 Git LFS 屬性。

## 訓練與評估結果

`train_bert.py` 在專案 `.venv` 與 GTX 1660 Ti 上完成 5 epochs，共 520 optimizer steps；過程沒有 FP16 NaN 或 CUDA OOM。以驗證集 macro-F1 選出的 best model 位於第 500 步，驗證 macro-F1 為 **0.8896**。訓練結束後載入該模型，對之前未參與選模的 416 筆 test set 評估一次：accuracy **0.8678**、macro-F1 **0.8603**。模型本體保存在 [`output/bert_emotion_clf`](../output/bert_emotion_clf)，所有 `checkpoint-*` 已清理。

分類報告顯示開心語調 F1 最高（0.9412），厭惡語調最低（0.7750）；其餘逐類數據見 `classification_report.json`。圖檔已產生：[`loss_curve.png`](../images/loss_curve.png)、[`f1_curve.png`](../images/f1_curve.png)、[`confusion_matrix.png`](../images/confusion_matrix.png)。混淆矩陣可見厭惡語調 40 筆中判對 31 筆，疑問語調 38 筆中判對 29 筆。

`infer_bert.py` 已輸出作業要求的五句，格式與四位小數均正確：

```text
我每天都能跟她一起上學，我好開心！ => 開心語調 (0.9887)
最好的朋友要離開臺灣了，以後可能不容易再見面... => 悲傷語調 (0.9874)
我覺得我快不行了... => 悲傷語調 (0.9771)
剛剛收到研究所錄取的通知書！ => 開心語調 (0.9880)
今年的冬天好像比較晚來。 => 平淡語氣 (0.9846)
```

以上是單次訓練與固定切分的結果。softmax 分數反映模型對其預測標籤的偏好，尚未做機率校準。

資料準備再次用 `--force` 執行後，train、valid、test JSONL 與 label map 的 SHA-256 均未改變。也已檢查模型 `config.json` 的 `label2id` / `id2label` 與資料對照一致、最終目錄只有一個 `.safetensors` 權重檔、過程 checkpoint 已清空、三張圖均存在。

## 重現命令

在 `hw1_bert_emotion` 資料夾中按 [`README.md`](../README.md) 安裝環境，再依序執行：

```powershell
.\.venv\Scripts\python.exe check_gpu.py
.\.venv\Scripts\python.exe download_data.py
.\.venv\Scripts\python.exe prepare_data.py
.\.venv\Scripts\python.exe train_bert.py
.\.venv\Scripts\python.exe plot_bert_metrics.py
.\.venv\Scripts\python.exe infer_bert.py
```

既有切分檔保留，重跑 `prepare_data.py` 若要改變切分，須明確加 `--force`。此專案的 GitHub 倉庫為 https://github.com/jajameme/hw1-chinese-emotion-bert；寄件仍需班別與姓名。模型權重使用 Git LFS 追蹤。
